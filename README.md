# game-kit

The shared kit for ORC PUNK's web games: keyboard and touch input, the action map both feed, the game
clock, screen navigation, the page-mount contract, and cleanup on exit.

This repo is new. The kit itself still lives in the Cemetery Security repo and is being moved here;
the plan for that move is `specs/game-kit.md`, arriving as this repo's first pull request. Until that
plan is approved and built, nothing here is used by any game.
